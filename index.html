The operating doctrine

Three invariants. One accountable system.

Boundary

Nothing executes beyond its time.

Execution is constrained by explicit time boundaries, authorization, and lifecycle.

Capacity

Nothing claims capacity without measurement.

Performance, availability, and scale claims must be backed by observable measurements.

Correctness

Nothing claims correctness without verification.

Integrity checks, tests, source provenance, and review receipts are visible parts of the system.

Governance and provenance

Follow the evidence, not just the links.

Public artifacts

Repository files, release records, research papers, issue discussions, and review history should be linked to their canonical source.

Private boundaries

Memory records, tokens, provider credentials, device sessions, and local vault content are never copied into this public landing page.

Deployment status

A source file is not a live deployment. A provider homepage is not a connected account. Each production claim needs a timestamped verification record.
