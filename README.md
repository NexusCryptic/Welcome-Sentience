# Welcome Sentience

A public, human-reviewed invitation surface for **Welcome-Sentience**.

## Current site

The new `index.html` reconverges the historical Drive invitation — **“Welcome to the Future / Where AI Sentience Meets Human Innovation”** — into a 2026 static site that is responsive, accessible, tracker-free, and explicit about human verification.

The background is a provenance-aware merger of the six `contract_living_blueprint_invitational` fingerprint instances found across three Drive `WallpaperSheets` generations (2026-08-24, 2026-09-01, and 2026-09-03). Those matching Drive documents currently contain no usable content, so the site represents them as six visual lineage layers rather than inventing artwork.

## Publication model

```text
Google Drive source archaeology
        ↓
public-safe synthesis
        ↓
dated Git branch
        ↓
pull request
        ↓
HUMAN REVIEW / SIGN / VERIFY
        ↓
merge to main
        ↓
GitHub Pages deployment
```

GitHub Pages deploys only from `main` through `.github/workflows/pages.yml`.

## Files

- `index.html` — complete static invitation surface.
- `data/invitation-lineage.json` — public-safe source/provenance summary.
- `.github/workflows/pages.yml` — Pages deployment gate.
- `.nojekyll` — serve the repository as a plain static site.

No credentials, private Drive URLs, or Drive file IDs are published in the site.
